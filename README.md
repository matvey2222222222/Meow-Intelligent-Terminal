**Meow Intelligent Terminal** — это умная и невероятно удобная замена стандартному `cmd.exe` для Windows. Терминал понимает вас с полуслова, мгновенно исправляет опечатки, подсказывает команды из истории и напоминает о важном.

---

## ✨ Что нового в v1.1.3?

- **⚡ Мгновенная автокоррекция**: Больше никаких раздражающих вопросов `[y/N]`. Если вы ввели `dri` или `sl`, терминал **сам** поймёт, что такой команды не существует, и мгновенно выполнит `dir` или `ls`. 
- **🧠 Умное исправление подкоманд**: Терминал знает популярные инструменты. Опечатка в `git statsu` или `pip instal` будет автоматически исправлена на `git status` и `pip install`.
- **🛡️ Права администратора**: Терминал запускается с повышенными правами (UAC), что избавляет от проблем с доступом к системным файлам и папкам.
- **📦 Огромный арсенал (70+ команд)**: Встроены мощные утилиты для работы с текстом, хэшами, дисками и файлами — всё работает на чистом Python и не требует вызова внешних процессов.

---

## 🚀 Скачать и запустить

**Устанавливать ничего не нужно** — терминал поставляется как один портативный `.exe` файл.

1. Открой раздел [**Releases**](../../releases)
2. Скачай последний `MeowTerminal.exe`
3. Положи в удобную папку, например `C:\MeowTerminal\`
4. Двойной клик — и терминал готов к работе (система запросит права администратора).

**Требования:** Windows 10 / 11 (x64).

## 📖 Как пользоваться

### Умные подсказки и автокоррекция

| Действие | Что произойдёт |
| :--- | :--- |
| Ввести `dri` | 🐾 Мгновенно выполнится `dir` (Автоисправление) |
| Ввести `git psuh` | 🐾 Автоматически сработает `git push` |
| Нажать `Tab` | Умное автодополнение (Fuzzy-поиск) |
| Нажать `→` | Принять серую ghost-подсказку из истории |
| Ввести `git statsu` | 🐾 Спросит подтверждение (так как `git` существует) |

### Встроенные команды (работают без cmd/PowerShell)

Теперь терминал может похвастаться полноценным набором утилит, разделённых по категориям:

| Группа | Команды |
| :--- | :--- |
| **Файлы** | `ls`, `dir`, `cd`, `pwd`, `cat`, `head`, `tail`, `wc`, `mkdir`, `rm`, `cp`, `mv`, `touch`, `tree`, `find`, `grep`, `ln` |
| **Диск и метаданные** | `stat`, `file` (тип файла по сигнатуре), `du` (размер папок), `df` (свободное место) |
| **Текст и фильтры** | `sort`, `uniq`, `rev`, `tac`, `nl`, `cut`, `tr`, `diff`, `cmp` |
| **Хэш и кодирование** | `hash`, `sha256`, `md5`, `sha1`, `base64`, `json`, `hexdump`, `xxd` |
| **Утилиты и пути** | `basename`, `dirname`, `realpath`, `which`, `seq`, `yes`, `mktemp` |
| **Система** | `echo`, `whoami`, `hostname`, `date`, `time`, `env`, `uname`, `uptime`, `sleep`, `cls`, `open`, `notepad` |
| **Управление** | `shell cmd`, `shell powershell`, `meow` |

### Напоминания и уведомления

```bash
meow remind 14:30 "Позвонить маме"       # абсолютное время
meow remind +5m "Проверить почту"        # через 5 минут
meow remind +2h "Созвон с командой"      # через 2 часа
meow remind 9:00 "Стендап" daily         # каждый день
meow remind 18:00 "Отчёт" weekly         # каждую неделю

meow list                                # список всех напоминаний
meow del <id>                            # удалить напоминание по ID
meow clear reminders                     # удалить все напоминания
